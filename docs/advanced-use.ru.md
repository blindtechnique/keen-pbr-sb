# Подробная установка и технические настройки

Основные возможности и повседневные действия описаны в [README](../README.md). Здесь собраны команды и детали для установки, диагностики и нестандартной настройки.

## Установка

Нужны Keenetic/Netcraze с Entware в `/opt`, SSH-доступ от `root` и компоненты прошивки для policy routing и netfilter. Для правил по доменам клиенты должны использовать DNS роутера.

Для обычной установки последней стабильной версии используйте команду с `wget` из [README](../README.md#установка). Команды ниже нужны только для установки конкретной тестовой версии.

При переходе со старых выпусков учитывайте совместимость: новый установщик принимает подписанные пакеты. Если в Latest ещё находится неподписанный `v3.0.7-sb.11`, он остановится до установки пакета. Дождитесь подписанного стабильного выпуска либо явно выберите тестовый выпуск командой ниже.

Перед их выполнением проверьте наличие `v3.3.1-sb.12` и пакета для своей архитектуры в [Releases](https://github.com/blindtechnique/keen-pbr-sb/releases). Команда ниже устанавливает именно этот выпуск, независимо от того, какой выпуск назначен стабильным:

```sh
(
  set -e
  installer=$(mktemp /tmp/keen-pbr-sb-install.XXXXXX)
  trap 'rm -f "$installer"' EXIT
  wget -O "$installer" https://raw.githubusercontent.com/blindtechnique/keen-pbr-sb/v3.3.1-sb.12/install.sh
  KEEN_PBR_UPDATE_RELEASE_TAG=v3.3.1-sb.12 sh "$installer"
)
```

Если вы используете уже установленный `curl`, замените строку загрузки на:

```sh
curl -fL https://raw.githubusercontent.com/blindtechnique/keen-pbr-sb/v3.3.1-sb.12/install.sh -o "$installer"
```

Установщик определяет архитектуру, проверяет пакет и предлагает настройку авторизации, DNS и дополнительных компонентов. Закреплённая для этого выпуска версия sing-box — **1.13.14**; уже установленный sing-box можно сохранить. nfqws2 устанавливается официальным пакетом отдельно, с согласия пользователя.

Панель открывается по адресу `http://<адрес-роутера>:12121`. Внешний доступ включается отдельно и требует авторизации. Для нативного импорта WG/AWG также нужен поддерживаемый прошивкой способ управления KeeneticOS.

## Обновление

Для обычного обновления используйте настройки панели или установленный скрипт:

```sh
/opt/usr/lib/keen-pbr/self-update.sh
```

Они выбирают опубликованный стабильный выпуск. Для добровольного обновления существующей установки до версии 12, пока она помечена как предварительная, после появления её файлов используйте:

```sh
(
  set -e
  installer=$(mktemp /tmp/keen-pbr-sb-install.XXXXXX)
  trap 'rm -f "$installer"' EXIT
  wget -O "$installer" https://raw.githubusercontent.com/blindtechnique/keen-pbr-sb/v3.3.1-sb.12/install.sh
  KEEN_PBR_UPDATE_RELEASE_TAG=v3.3.1-sb.12 sh "$installer" --update
)
```

Перед обновлением скачайте резервную копию и сохраните прежний IPK. `--update` переносит настройки без повторного начального мастера. Для старой установки `v3.0.7-sb.11` установщик при необходимости добавляет OpenSSL. Переход реализован без промежуточного пакета, но полноценная проверка обновления реального роутера со stable11 с OpenSSL и без него ещё не объявлена завершённой.

Первая загрузка установщика и доверенного ключа опирается на HTTPS GitHub. Уже установленные подписанные версии проверяют подпись установщика до запуска. Прямой `opkg install` не выполняет проверки подписи средствами проекта. Подробнее: [переход со stable11](upgrading-stable11.md), [подпись выпусков](keenetic-release-signing.md).

## Как устроены подключения

Маршруты, метки и правила находятся под управлением keen-pbr. sing-box используется для прокси-подключений и запускает TUN-интерфейсы с `auto_route: false`, не создавая параллельную схему маршрутизации. Нативные VPN Keenetic и подключения sing-box могут быть целями одних и тех же правил и групп.

Транспорт — физическое VPN/прокси-подключение. Исходящее соединение — цель правила: интерфейс, группа, прямой выход или блокировка. При импорте через панель связанное исходящее соединение создаётся автоматически.

У sing-box доступны два режима:

- **Изолированный:** отдельный процесс для каждого подключения; используется по умолчанию.
- **Общий:** один процесс обслуживает несколько TUN-интерфейсов; меньше расход памяти, но его сбой затрагивает весь этот набор подключений.

Адрес сервера может потребовать исключения из VPN-маршрутизации, чтобы подключение не пыталось идти через себя. Для этого панель предлагает отдельное подтверждаемое действие; не считайте исключение автоматически добавленным при любом импорте.

## Форматы подключений

| Формат | Подключение |
|---|---|
| `.conf`, `.vpn`, `vpn://` | WireGuard/AmneziaWG; поддержка параметров зависит от KeeneticOS |
| `vless://`, `vmess://` | VLESS, включая REALITY, и VMess |
| `trojan://`, `ss://` | Trojan и Shadowsocks |
| `hysteria2://`, `hy2://`, `tuic://` | Hysteria2 и TUIC |
| `anytls://` | AnyTLS |
| `socks://`, `socks5://`, `http://`, `https://` | SOCKS и HTTP-прокси |
| JSON | Outbound, поддерживаемый установленной сборкой sing-box |

Подписки VPN и списки доменов/IP — разные сущности. Подписки обновляют подключения, списки определяют, какой трафик направлять через них. Автообновление подключений поддерживает URI/base64-подписки, но не полный sing-box JSON с `outbounds`. Восстановление архива настроек не запускает скрытую загрузку всех источников из сети.

## DNS и списки сайтов

dnsmasq связывает ответы DNS с адресными наборами для правил. Если устройство использует сторонний DoH или собственный VPN, роутер может не увидеть имя сайта. Принудительный DNS перехватывает обычный DNS на порту 53; блокировка DNS-over-TLS на 853 не означает универсальную блокировку DoH на 443. [Настройка Secure DNS](browser-secure-dns.md).

Поддерживаются текстовые списки, JSON-массив строк, YAML `payload` и бинарные rule-set `.srs`. [Форматы импорта](list-source-formats.md).

SRS версий 1–5 читается самим keen-pbr-sb; sing-box для этого не нужен. Доменные суффиксы и IP/CIDR переносятся без изменения смысла; точные SRS-домены получают принятую в списках семантику «сам домен и поддомены». Регулярные выражения, ключевые слова, инвертированные и зависимые от дополнительных условий правила пропускаются с предупреждением о частичном импорте.

`geoip.dat` и `geosite.dat` Xray не поддерживаются. Используйте отдельные доменные/IP-списки или совместимые `.srs` вместо монолитной базы.

## nfqws2 и журналы

nfqws2 — отдельный официальный пакет, а не часть IPK keen-pbr-sb. Панель управляет службой, конфигурацией, стратегиями, списками и Lua-файлами. Открытие страницы не перезапускает службу.

Поддерживаемые профили ротации сохраняют подтверждённые удачные варианты периодически: не каждый последний выбор гарантированно записан до внезапного отключения питания. При обновлении через панель управляемые Lua-файлы восстанавливаются до запуска nfqws2; обновление сторонним инструментом не считается тем же сценарием.

Очистку журналов можно ограничить возрастом и/или размером. Строки без распознаваемой даты не удаляются по возрасту; лимит размера действует независимо. Резервная копия keen-pbr-sb не заменяет резервную копию прошивки Keenetic. Архивы подключений могут содержать ключи, пароли и приватные ссылки.

## Файлы и диагностика

| Путь | Содержимое |
|---|---|
| `/opt/etc/keen-pbr/config.json` | Настройки маршрутизации и панели |
| `/opt/etc/keen-pbr/transports.json` | VPN/прокси-подключения и их секреты |
| `/opt/etc/keen-pbr/subscriptions.json` | Подписки, расписания и привязки |
| `/opt/etc/keen-pbr/auth.json` | Авторизация панели |
| `/opt/etc/keen-pbr/nfqws-strategies` | Пользовательские стратегии |
| `/opt/etc/nfqws2` | Файлы nfqws2 |
| `/opt/var/cache/keen-pbr` | Кэш и загруженные списки |
| `/opt/var/log/keen-pbr.log` | Журнал, если запись включена |

```sh
/opt/etc/init.d/S80keen-pbr status
/opt/etc/init.d/S79transport-manager status
/opt/bin/sing-box version
```

Начинайте диагностику с состояния служб, проверки сайта в панели и настроек DNS клиента. Подробные сведения: [соединения](CONNECTIONS.ru.md), [фоновые задачи](background-task-diagnostics.md). Перед публикацией отчёта удалите личные адреса, ссылки подписок и секреты.

Удаляйте сервис штатным `uninstall.sh`, указанным в README. Прямой `opkg remove keen-pbr` оставляет аварийный загрузочный guard для сценариев переустановки. Откат бинарного пакета требует сохранённого прежнего IPK; локальная копия настроек сама по себе его не заменяет.
